| ------- | ------------------ | ----------------------------------------- |
| 最高      | 第 1 章 Agent 基础     | Agent 不只是聊天，而是“思考 → 调用工具 → 观察结果 → 再行动”的循环 |
| 最高      | 第 2 章 上下文工程        | Agent 能力很大程度取决于它看到了什么、信息如何组织              |
| 高       | 第 3 章 记忆和知识库       | 用户记忆、RAG、向量检索、混合检索、知识库治理                  |
| 高       | 第 4 章 工具           | 如何设计工具、MCP、权限控制、安全防护、异步任务                 |
| 高       | 第 5 章 Coding Agent | 文件系统、代码执行、测试和版本控制如何增强 Agent               |
| 最高      | 第 6 章 Agent 评估     | 如何判断 Agent 真的变好了，而不是“偶尔答对”                |

尤其要记住：

1. **模型本身不等于 Agent**。真正的 Agent 还需要上下文、工具、状态管理、安全机制和验证机制。
2. **上下文质量决定能力上限**。系统提示词、历史消息、工具描述、工具结果、环境状态都会影响模型决策。
3. **工具应少而通用**。与其设计很多专用工具，不如提供文件读写、搜索、代码执行等可组合的基础能力。
4. **代码是 Agent 的可靠执行和验证手段**。测试、类型检查、Git、沙盒，都可以成为 Agent 的“护栏”。
5. **没有评估，就没有真正的迭代**。每次修改都应该通过固定测试集、指标和对比实验验证。
6. **事实知识适合放在 RAG/知识库中，行为习惯才适合通过训练固化到模型参数中。**

## 对新手来说的主要难点

### 1. 上下文工程

这是全书最核心、也最容易抽象的一章。难点包括：

* 理解“上下文”不只是聊天记录；
* 区分系统提示词、工具定义、工具结果和历史轨迹；
* 理解上下文压缩、记忆、Skills 的区别；
* 理解 KV Cache 为什么要求固定前缀；
* 处理上下文过长、信息丢失和模型注意力下降。

第 2 章的 KV Cache 原理可以先跳过，先记住书中的三条实践规则：

* 系统提示词和工具定义尽量保持不变；
* 动态信息追加到消息末尾；
* 使用标准 API 消息格式，不要自行拼接成普通字符串。

### 2. RAG 和知识库

RAG 表面上是“搜索文档再回答”，实际涉及：

* 文档如何分块；
* 向量检索和关键词检索的区别；
* 混合检索和重排序；
* 检索结果是否真的相关；
* 知识冲突、过期和隐私问题；
* Agent 是否知道“什么时候应该搜索”。

新手不要一开始就研究 GraphRAG、RAPTOR，先理解最基本的：

> 文档分块 → 建立索引 → 检索相关内容 → 放入上下文 → 生成回答

### 3. 工具安全和异步 Agent

工具让 Agent 能操作现实世界，也带来风险：

* 删除文件、发送邮件、转账等不可逆操作；
* 提示注入和工具描述投毒；
* 权限越界；
* 工具执行失败后的重试循环；
* 并行任务、取消任务和状态管理。

书中强调，生产级 Agent 必须有输入防护、执行防护、输出检查和必要的人工确认。

### 4. Agent 评估

这是很多初学者容易忽略、但工程上极重要的部分。难点是：

* 如何设计真实而不泄漏答案的测试任务；
* 如何评价多轮工具调用；
* LLM-as-a-Judge 是否可靠；
* 如何区分“能力提升”和“偶然答对”；
* 如何把评估结果转化为系统改进。

核心闭环是：

> 观察 → 提出假设 → 做实验 → 验证 → 修改系统 → 再评估

### 5. SFT 和强化学习

第 7 章是全书技术门槛最高的章节之一，需要机器学习基础。重点关系是：

* **SFT**：让模型学会稳定的格式、协议和示范行为；
* **RL**：让模型通过奖励和试错学习更好的策略；
* 训练前需要可靠的环境、数据和奖励设计；
* 多轮 Agent 中最难的是“最终结果应该归因给哪一步”。

如果你是开发新手，第 7 章可以后读。

## 建议阅读顺序

1. 先补 Python、命令行、JSON、HTTP API、Git 基础。
2. 阅读第 1 章，重点理解 Agent 循环和 Harness。
3. 阅读第 2 章的 API 调用、提示工程、Skills、上下文压缩。
4. 阅读第 3 章的基础 RAG 和用户记忆。
5. 阅读第 4 章的工具设计和安全。
6. 阅读第 5 章，实际做一个简单 Coding Agent。
7. 阅读第 6 章，给自己的 Agent 建立测试集。
8. 最后再根据方向选择：
   * 模型训练：第 7 章；
   * Agent 自我学习：第 8 章；
   * 语音、GUI、机器人：第 9 章；
   * 多 Agent 系统：第 10 章。

对你目前最值得先掌握的不是复杂算法，而是这条主线：

> **让模型看见正确的信息，给它有限且安全的工具，让它执行后得到真实反馈，再用测试验证结果。**
